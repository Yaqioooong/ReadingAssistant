# 第 02 章 P1 解析器

> 对应阶段：P1 解析器 —— `BookParser` 抽象基类 + txt / epub / pdf / docx 四类解析器 + 工厂分发。

## 本章目标

把四种格式的电子书统一解析成**纯文本 + 元数据**，并让调用方「只看扩展名就能拿到正确解析器」。核心是三个设计：统一数据结构、统一抽象接口、工厂注册。

## 步骤拆解

### 步骤 1：定义数据结构和异常（`parsers/base.py`）

**做什么**：定义 `Chapter` / `ParsedBook` 两个 dataclass 和一套异常体系。

**为什么**：上层（分块、入库、检索）只认 `ParsedBook`，不关心书是什么格式。

```python
@dataclass
class Chapter:
    title: str
    content: str

@dataclass
class ParsedBook:
    title: str
    author: str | None = None
    chapters: list[Chapter] = field(default_factory=list)

    @property
    def full_text(self) -> str:
        return '\n\n'.join(chapter.content for chapter in self.chapters)
```

**异常分层**（都继承 `ParseError`，调用方只需捕获一个基类）：

```python
class ParseError(Exception): ...            # 文件缺失 / 损坏 / 无文本
class UnsupportedFormatError(ParseError): ...  # 扩展名不支持
class EncryptedFileError(ParseError): ...      # PDF 加密
```

**注意**：`UnsupportedFormatError` 是 `ParseError` 的子类，`except` 分支要先写子类再写基类，否则子类异常会被基类吞掉。

### 步骤 2：抽象基类 `BookParser`

```python
class BookParser(ABC):
    extensions: frozenset[str] = frozenset()   # 类属性：声明支持的扩展名

    @abstractmethod
    def parse(self, path: str | Path) -> ParsedBook:
        """将电子书解析为纯文本 + 元数据。"""
```

**为什么用 `frozenset`**：扩展名集合不可变，且能直接做成员判断。**为什么是类属性**：工厂要靠它分发，不需要实例。

### 步骤 3：统一路径解析 `resolve_book_path`

**做什么**：让相对路径在**任何工作目录**下都能解析——先按字面路径找，找不到再按仓库根目录找。

**为什么**：否则用户在 `/tmp` 运行 `parse_book('data/books/sample_book.txt')` 会得到莫名其妙的「文件不存在」。

```python
def resolve_book_path(path: str | Path) -> Path:
    literal = Path(path)
    if literal.is_file():
        return literal
    repo_relative = Path(get_abs_path(str(literal)))
    if repo_relative.is_file():
        return repo_relative
    return literal
```

每个解析器 `parse()` 开头先 `path = resolve_book_path(path)`，再检查 `path.is_file()`，缺失文件统一报「文件不存在」（而不是各格式各自报「文件损坏」）。

### 步骤 4：TxtParser（`txt_parser.py`）

**做什么**：自动探测编码 + 按章节标题行切分。

**编码探测**：中文 txt 常见 `utf-8` / `gb18030` / `big5`，按优先级逐个尝试，失败就换下一个：

```python
_ENCODINGS = ('utf-8', 'gb18030', 'big5', 'latin-1')
for encoding in _ENCODINGS:
    try:
        return path.read_text(encoding=encoding)
    except (UnicodeDecodeError, UnicodeError):
        continue
raise ParseError(f'无法识别文件编码: {path}')
```

**章节切分**：用正则识别「第X章 / Chapter N / 序章」开头的行作为新章节起点，正文按行累积。用「flush 函数」统一收尾，避免最后一个章节漏掉：

```python
def flush() -> None:
    content = '\n'.join(current_lines).strip()
    if current_title or content:
        chapters.append(Chapter(current_title or '正文', content))
    current_title = ''
    current_lines = []

for line in text.splitlines():
    stripped = line.strip()
    if stripped and _CHAPTER_RE.match(stripped):
        flush()
        current_title = stripped
    else:
        current_lines.append(line)
flush()
```

**技巧**：写解析器时先想清楚「空文件、全是标题、没有标题」三种情况，分别处理（空文件直接 `ParseError('文件为空')`）。

### 步骤 5：EpubParser（`epub_parser.py`）

**做什么**：用 ebooklib 读取 EPUB，按 **spine（阅读顺序）** 抽取章节正文，剥离 HTML。

```python
book = epub.read_epub(str(path))
title = values[0][0] if (values := book.get_metadata('DC', 'title')) else path.stem

for idref, _linear in book.spine:
    item = book.get_item_with_id(idref)
    ...
```

**大坑（实测）**：ebooklib 0.19 把 EPUB3 导航页 `nav.xhtml` 的类型也标成 `ITEM_DOCUMENT`，只按类型过滤会把它当成正文章节。必须**按文件名**排除导航页：

```python
name = (item.get_name() or '').lower()
if item.get_type() != ebooklib.ITEM_DOCUMENT or name.startswith(('nav', 'toc', 'ncx')):
    continue
```

**HTML 剥离**：`BeautifulSoup(content, 'html.parser')` + 删掉 `script` / `style` + `soup.get_text('\n')`。章节标题优先取 `<h1>/<h2>/<h3>`，没有就取正文第一行。

### 步骤 6：PdfParser（`pdf_parser.py`）

**做什么**：pypdf 逐页提取文本 + 元数据；加密 PDF 明确报错。

**pypdf 5.x 语法要点**：

```python
from pypdf import PdfReader
from pypdf.errors import PdfReadError   # 注意：5.x 不再从顶层导出 PdfReadError！

reader = PdfReader(str(path))
if reader.is_encrypted:
    raise EncryptedFileError(f'PDF 已加密，暂不支持密码解锁: {path}')
pages = [page.extract_text() or '' for page in reader.pages]
```

**为什么 PDF 是单章节**：PDF 没有可靠的结构信息（不像 EPUB 有 spine、DOCX 有 Heading），诚实做法是整体作为「正文」一个章节，等后续做页码级解析再增强。

### 步骤 7：DocxParser（`docx_parser.py`）

**做什么**：python-docx 按 **Heading 样式**切分章节，元数据取 core properties。

```python
from docx import Document
from docx.opc.exceptions import PackageNotFoundError

document = Document(str(path))
style_name = (para.style.name or '').lower() if para.style else ''
is_heading = style_name.startswith('heading')   # 'Heading 1' -> 'heading 1'
title = document.core_properties.title or path.stem
```

**注意**：样式名要先 `.lower()` 再判断，兼容 'Heading 1' 的大小写变体。

### 步骤 8：工厂（`factory.py`）

**做什么**：按扩展名分发 + 一个 `parse_book()` 总入口。

```python
_REGISTRY: tuple[type[BookParser], ...] = (TxtParser, EpubParser, PdfParser, DocxParser)

def get_parser(path: str | Path) -> BookParser:
    extension = Path(path).suffix.lower()          # 统一小写，大小写不敏感
    for parser_cls in _REGISTRY:
        if extension in parser_cls.extensions:
            return parser_cls()
    raise UnsupportedFormatError(f'不支持的电子书格式: {extension or "(无扩展名)"}')

def parse_book(path: str | Path) -> ParsedBook:
    return get_parser(path).parse(path)
```

**设计要点**：新增格式 = 写一个 `BookParser` 子类 + 加进 `_REGISTRY`，调用方零改动（这就是 AGENTS.md 里说的「解析器可插拔」）。

### 步骤 9：文件命名 `format_parser.py`

项目约定每个解析器文件用 `txt_parser.py` / `epub_parser.py` / `pdf_parser.py` / `docx_parser.py` 命名，一眼看出文件格式与职责。类名仍用 `TxtParser` 等。

## 测试技巧：动态生成测试文件

测试不依赖仓库里的静态样书，而是**在测试里现场生成**，保证可重复：

- **TXT / DOCX**：直接 `write_text` / python-docx 生成。
- **EPUB**：用 ebooklib 现造一本（`EpubBook` + `EpubHtml` + `write_epub`）。
- **PDF**：手写一个最小合法 PDF（必须正确写 xref 偏移表，pypdf 才读得动），几行代码即可。
- **加密 PDF**：pypdf 的 `PdfWriter.append(reader)` + `writer.encrypt('secret')`。

边界用例清单：空文件、损坏文件、加密 PDF、无章节标题文本、非 UTF-8 编码、不支持的扩展名。

## 关键语法与技巧

- dataclass + `field(default_factory=list)`：可变默认值必须用工厂函数，直接 `[]` 会共享同一个列表。
- `re.escape()`：用正则切分时如果分隔符含特殊字符，先 `re.escape`。
- 异常 `from exc`：`raise ParseError(...) from exc` 保留原始 traceback 链，调试友好。
- 解析器只做「文件 → 文本」，不做业务判断（去重、入库都在后面阶段），职责单一。

## 常见坑

1. pypdf 5.x 的 `PdfReadError` 在 `pypdf.errors` 子模块，顶层导入会 `ImportError`。
2. EPUB 导航页伪装成 `ITEM_DOCUMENT`，必须按文件名过滤。
3. 缺失文件在 epub/pdf/docx 里可能被误报成「文件损坏」——统一在 `parse()` 开头先做存在性检查。
4. 损坏的 EPUB 抛出的异常类型不固定，用宽泛 `except Exception` 包一层转成 `ParseError`。
